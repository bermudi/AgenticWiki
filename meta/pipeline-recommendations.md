# Pipeline Recommendations

This is the durable queue for **process** recommendations from filing evaluations, audits, and verification reviews. `meta/tech-debt.md` tracks page/source evidence debt; this ledger tracks changes to the workflow that produces and checks wiki artifacts.

A recommendation is not closed merely because a skill was edited. Keep it `open` until the implementation is present **and** the stated closure evidence has been observed in a later run. AG-000 is the explicit bootstrap exception: creating the durable ledger is itself its closure event. Retain closed rows so repeated recommendations have a visible history instead of evaporating into evaluation prose.

## Status contract

- `open` — the recommendation is unresolved, or its implementation has not yet been demonstrated by the closure evidence.
- `closed` — the implementation is present and the closure evidence has been recorded in this row.

The filing coordinator owns ledger updates. When a run tests a recommendation, update its implementation/evidence columns in the same changeset as the filing report or audit note. Every closure record must cite the observation date and at least one durable commit, session, or run identifier; prose such as “observed later” is not closure evidence. Add recurring process recommendations here rather than burying them in content-debt rows.
